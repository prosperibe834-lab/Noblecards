# NobleCards Wallet Module UI/UX Design Instructions

This Wallet module is for the NobleCards Flutter application.

I want you to build it to the quality of the world's best fintech apps such as Revolut, Wise, Monzo, Cash App, Chime, Binance, Coinbase, Bybit, PalmPay and Opay.

The design should feel premium, clean, modern, smooth, minimal and luxurious.

DO NOT use Bottom Navigation because I already have one.

DO NOT use Emoji icons.

Use ONLY Boxicons throughout the entire Wallet module.

Everything must support both Light Mode and Dark Mode using the existing Theme files I already have.

Use the spacing, border radius, typography, colors, shadows, animations and theme constants from my existing theme files instead of hardcoding values.

For gradients, if you believe a subtle gradient will improve the UI while keeping it premium, feel free to use it.

Use reusable widgets whenever possible.

Every page must have beautiful page transitions.

Use Hero animations where appropriate.

Use smooth fade animations, slide animations and scale animations.

Every button should have ripple animation.

Cards should have subtle elevation.

Lists should animate while loading.

Use shimmer loading placeholders.

Every screen should be responsive.

Every code you send me MUST tell me:

• Which file to create
• Which folder to create it inside
• Where to paste the code
• If an existing file should be modified

Never leave me guessing.
