# NobleCards – Complete Redesign of Withdraw Module (Frontend Only)

Do **NOT** reuse the previous Withdraw screen. That design is too basic and does not match the quality of a modern global fintech application.

NobleCards is a worldwide gift card marketplace, so the withdrawal experience must feel premium, professional, secure, and scalable.

## IMPORTANT

The screen that navigates to the Withdraw page **already displays:**

* Available Balance
* Pending Balance

**Do NOT duplicate those on the Withdraw screen.**

# Payment Gateway Considerations

Structure the withdrawal flow so it can later integrate with providers such as:

* Flutterwave
* Paystack
* Wise
* PayPal
* Skrill
* Payoneer

When the backend is implemented, the app should be able to send payouts through supported providers depending on the user's country and selected withdrawal method.

Saved withdrawal accounts should be reusable so users don't need to enter the same information every time.
